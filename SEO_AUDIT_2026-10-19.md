## Scope
Technical SEO and consent/AdSense improvements based on Search Console screenshots dated 12 Oct 2026.

## Verified at code level
- A correct sitemap and permissive robots route already exist. We did not turn off indexing or add blanket redirects.
- Both sites have `pub-8337311370258201` in `public/ads.txt`.
- Search Console has **10 indexed**, **199 discovered but not indexed**, **2 missing (404)** and **1 redirect**.
- English home linked to English country pages, but localized salary alternatives were previously mainly reachable via JavaScript controls or XML metadata.
- The AdSense library was being loaded before the site's consent choice.

## Changes in this branch
- Crawlable language links from the homepage and on every country calculator.
- AdSense script is now opt-in (analytics and advertising consent are separate).
- Cookie policy discloses optional advertising in 4 languages.
- Static export audit tool `npm run seo:check`, plus PR build checks.

## After merging and deploying
1. Confirm both `https://netsalarymap.online/robots.txt` and `/sitemap.xml` return HTTP 200 and correct content type.
2. Confirm `/ads.txt` returns 200, plain text and the correct publisher ID.
3. Run `npm run build && npm run seo:check` in a Node 22 checkout. Review GitHub Actions.
4. Use Search Console → Indexing → Pages → **Discovered - currently not indexed** → Export for the full 199 URLs. Verify the representative `/de/gehalt/deutschland`, `/salary/germany`, `/es/salario/espana` in URL inspection using **Test live URL**.
5. Check Cloudflare deployment points to the new main commit and serves HTML from static export on deep URLs; compare canonical and language in **View source**.
6. Check the 2 actual 404 URLs in GSC. Redirect only if a *real matching replacement* exists, otherwise valid 404/410 is expected. Do not blanket-redirect missing URLs to the homepage.
7. Resubmit sitemap in Search Console if changed and request indexing for the handful of most useful pages rather than all 199. Google decides which pages to index.
8. In AdSense → Sites, confirm the site's status is **Ready**. If rejected, inspect the exact reason; correct site and resubmit. Verify ads.txt crawler status.
9. For users in EEA/UK/CH, configure a **Google-certified IAB TCF CMP** before serving personalized AdSense ads. The custom local preference dialog is *not* a substitute.
10. Enable Auto ads or provide approved manual slot IDs and check ads rendering after explicit consent. Do not expect revenue before AdSense site approval.
11. Monitor monthly landing pages, clicks, impressions, CTR, indexed pages and accepted ad requests; prioritize substantive country-specific content and authoritative backlinks.

## Known limitations
- Full Search Console URL exports, current live Cloudflare HTTP response headers, and AdSense review reason are not accessible from GitHub.
- The 199 discovered-but-not-indexed URLs are not evidence of 199 broken routes; the report shows they have not been crawled yet.
- An `ads.txt` file present in source cannot prove Cloudflare is serving it until HTTP is checked.
